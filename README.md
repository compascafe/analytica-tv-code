# AnalyticaTv — open code

Runnable code for the technical articles at [AnalyticaTv](https://analytica.tv/en/blog/).

Each folder under `posts/` matches an article slug and contains a `README.md` with the file list and run instructions. Everything is released under the MIT license unless a folder says otherwise.

Built for football analysts, data scientists and club/ops people who want to rerun the work, break it and adapt it.
